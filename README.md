# 网页移植版《国殇之血色狼烟》

纯静态网页、无服务器（本地起个 http.server 即可）。当前已实现：

- ✅ **等距地图**：地形瓦片 + **对象表**（整体精灵按 64×32 切片，与角色逐块深度排序；建筑/城墙/树木/装饰）
- ✅ **主角/NPC 动画**：读 `chars.json`（30 个模型、2777 帧），**8 方向朝向已校正**（0=N,2=E,4=S,6=W）
- ✅ **碰撞 + A\* 寻路**：地形用地图自带的 0/1 行走网格；**点击地面 / 按住移动 / 攻击追击都会用 A\* 绕开墙**（直线被挡时自动改走路径）；寻路结果经**像素级连续化**：A\*（相邻格）后用**角点路径**（`cornerPath`：候选点为各格菱形角点，贪心跳到沿路最远且像素级可见者，每段经 `walkableSegment` 校验）得到**贴着可走区域几何角点**的折线，不再沿格心走、不会左右摇摆；寻路可**把其它单位占据的格子视为障碍**（`findPath(..., { avoidUnits: true })`），不会再对着墙或同伴直撞；**移动时不再用单位硬碰撞**（避免两个迎面移动的单位互相顶死、原地踏步）——改用**每帧软分离**（重叠时沿法线+侧向分量把两者推开，只推到地形可走处，见 `systems/separation.js`）——**只推“正在移动”的一方**（静止单位不会被撞得位移，移动方自己让开/绕行；双方都移动时互相让开），既不会长时间叠在一起，也能从同伴/敌人身旁绕过去；**若终点被其它单位占据，走到贴身（碰撞接触距离）即视为“到达”并停下**——不会因挤不进同一点而原地踏步；出生/读档/地图切换时仍会把重叠单位挤到附近空位（死亡单位不阻挡）；**高精度移动**——终点取鼠标点击/按住位置的**像素坐标**（仅当目标格可走），不再只能停在格子中心；**按住期间持续跟随鼠标当前像素**（鼠标不动即停在鼠标处，鼠标细微移动也会立即跟进，无 8px 死区）
- ✅ **镜头跟随无抖动**：渲染时整帧只使用一个“取整后的相机偏移”，地形/建筑/角色/特效同步移动同一整数位移，不会因各自 `Math.round` 相差 1px 而出现地面与精灵相对晃动
- ✅ **完整 GSP 解释器**：`Say/Ask/if/else/endif/exit/end` 与约 60 条指令（重写为 generator VM）
- ✅ **剧情 / 任务 / 商店**：`main.gsp` 开场、`龙绝尘.gsp` 拜师链、`冰糖葫芦贩.gsp` 买卖
- ✅ **技能与战斗**：技能表、命中/伤害、怪物 AI（动物/人形敌人）、**死亡倒地动画**、**按 NPC 可配置的掉落**、任务计数；**近战命中在挥砍动画中段结算**（每次出手都从**动画首帧**开始并与挥砍计时同步，命中固定在刀砍中段/同一帧）；**攻击间隔以 `CFG.attackCD`（NPC 为 `npcAttackCD`）为准，挥砍动画按间隔自动加减速**；**挥砍期间锁定方向**（目标移动不会中途转向/切帧块闪回，收招后再转向）；**单位阵亡时先把当前这一刀打完再切换倒地（并取消该刀的伤害）**；**挥砍“提交”优先级最高——一旦出手就把整段动画播完，不因目标移动/离开近战/目标死亡而中断**；**后摇期间点地移动不会丢指令：挥砍播完后再继续走向新目的地**（清目标但**不清移动路径**）；玩家与 NPC 一致
- ✅ **NPC 行为**：平民/商人随机游荡，敌人主动追击；可攻击判定 = `攻击>0`（动物可打不主动，平民不可打）；**闲逛终点为格内任意点**（非格心）；**移动/追击速度与掉落可在编辑器内按 NPC 单独配置**
- ✅ **任务系统**：`CheckMission(未知名)=4`，能触发 `爹→拜师函`、`二婶→收集猴皮` 等初始任务；**接受收集类任务时立即结算背包已有物品**（先有猴皮再接任务也会直接计入）
- ✅ **仇恨与反击**：玩家一旦发起攻击就拉仇恨（**即使这一下未命中**），敌人立即开始反击
- ✅ **存读档**：`localStorage` 6 个槽（F5 开关）；序列化当前地图/主角/数值/背包装备/任务/变量/NPC 快照；**从标题菜单读档也能正确重建主角与相机**（本次会话尚未开局时主角不存在，读档会按存档坐标创建主角，避免地图被画到屏幕外而全黑）
- ✅ **音频**：每个地图自动播放其表头音乐（`city.wma→city.mp3` 自动转换）；**F10 设置面板**调背景音乐/音效音量（存 `localStorage`）
- ✅ **商店**：右键商人开启；与背包同款 `packpanel` 5×5 面板，**置于屏幕左侧**，与右侧背包并排；底部正中空格为**关闭按钮**（`closebtn`）；买入/卖出（不同商人不同货源，含音效）；**鼠标悬停商品/物品会在光标旁弹出小框**（名称/价格/等级限制/性能）
- ✅ **物品/装备栏**：快捷 1~9 + 武器/甲/饰品×2 + **右下角五个功能按钮**（属性/记事/荣辱/任务/菜单，**互斥**，再点关闭）；状态栏**数值显示在血/精/经栏内部**（居中描边）；左键拿起、右键使用/装备；“包裹”开 16 格背包；格子位置对齐 `userpanel.bmp` 的窗框
- ✅ **地面掉落物**：怪物死亡后掉落物**掉在地上**（小图标+投影）；掉落表优先取该 NPC 的 `drops`（编辑器可改），缺省时才回退到内置表（野猴→猴皮/猴肉、花豹→豹牙/豹肉）；左键点地物品会走过去自动拾取（**物品栏满则不拾取**）；从物品栏左键拿起再点地板即可丢下
- ✅ **交互细节**：商店/对话中左键点窗体外的地板会**关闭商店/中断对话**；商店选购后只能在“空格或可叠放格”上左键购入，在商店窗内其它位置左键 = 放下
- ✅ **NPC 行为**：无行走帧的 NPC（爹/娘/郎中等）原地站立；有行走帧的（小孩/王老伯）随机游走；敌人主动追打
- ✅ **死亡**：单位死亡只播一次对应方向的倒地动画并永久趴在地上（不消失）
- ✅ **主角阵亡回主菜单**：HP 归零并播完倒地动画后，短暂显示“正在返回主菜单…”，约 1.8s 自动回到标题菜单（切回标题音乐），可直接重新开始或读档
- ✅ **帧锚点校正 + 无闪烁**：从**抠图后**的 alpha 包围盒计算锚点——x 用“动作+方向块内各帧中心的中位数”（挥剑/摆臂不左右抽），y 用逐帧底边（脚永远踩在单位坐标上）；站立/行走/奔跑/攻击/倒地之间身体中心与脚底对齐（`anchors.json`）
- ✅ **对白内联颜色**：支持 `<2任务目标/>`、`<4物品·技能名/按键/>` 等标记，按 `TAG_COLORS` 上色，**自动按当前颜色断行**
- ✅ **建筑遮挡（多边形裁剪 / 屏风模型）**：每个对象拆成**两块用 Canvas `clip()` 多边形裁剪**的绘制物——**覆盖层 = 蓝线（黄线 − 玩家身高）以上**，沿斜线精确裁剪、排序键 `ROOF_TOP`（**高于所有角色**：只要屏幕重叠就遮挡玩家，不论玩家 y 是否在贴图之外/更靠前）；**基座 = 蓝线以下**，整块一个深度 = **黄线的最高点**（斜面上最小 y，不是最前/最深那个格）——这样角色站在黄色区域内基本都在其前方、稳定不被遮挡（用最前格会沿黄区走动时时遮时不遮）。因为边界是**沿斜线/贴图轮廓**的，遮蔽不会像轴对齐方格那样“横竖截断玩家半身”；玩家在对象前方→整幅露出，在后方→被轮廓自然遮住。**覆盖层无条件遮挡角色**（不做“门廊提升”：站在可走地基格上也不会被豁免，蓝区内的身体一律被盖住）。**地基线来源**：未手画时由引擎自动拟合——只在“地基格 x 范围内”取 alpha 底边、用**下凸包**（跨城门洞凹陷、忽略两侧房檐），并**舍去两端陡峭段**（“地基→飞檐顶”的近竖直连线）。**同一张贴图在不同地图里是同一个模板**（按贴图源矩形去重，如扬州与扬州_屠城共 45 个模板而非 186 个实例），地基线/深度模式只编辑一次、所有实例共享。**每个模板可选深度模式**（编辑器「装饰物」栏 / 地图装饰面板）：① 自动下凸包；② **手画地基线**（拆成两半的城门等自动不可靠时手描；青线自动跟随；可一键恢复自动；黄线可越出贴图，拖到下方即让青线覆盖整幅→完全遮蔽）；③ **整体单一深度**（树木/柱子等点状对象）。
- ✅ **死亡倒地动画**（只播一次）；**NPC 空闲对白**（无脚本 NPC 右键说话）
- ✅ 地图切换：`ChangeMap`/`LoadInitialMap`、**脚本触发器**（格子 `+0x1C`）、**地图直传**（格子 `+0x1D` → `maps.ini` + 入口点 `+0x44/0x48`）、NPC 动态增删
- ✅ **完整场景集**：原游戏 `map/` 下**全部 9 张地图**均已导出并随 `versions/default/assets/maps_manifest.json` 清单**全部预载**（含仅靠地图直传抵达、未被脚本直接引用的场景，如「战场」），不会因硬编码名单而漏掉任何一张
- ✅ **标题菜单 / 片头 / 结局**：忠实复刻原版 `game.ini` 的开场与收尾——片头闪屏（`team`→`kouhao`，可点击跳过）→ 标题菜单（`mainmenu` + 开始/载入/关于/退出，`start.mp3`）→ 游玩 → 结局（`end.png` + 结局评价称号 + 结局音乐）；菜单按钮坐标取自 `mainmenu.ini`
- ✅ **数据版本（内容包）**：原版数据永远是只读的**默认版本**；编辑器保存的修改成为**独立版本**，开始游戏前在「数据版本」中选择。支持新建 / 重命名 / 删除 / 导出 / 导入（`.gsxy.json`）
- ✅ **内置内容编辑器**（仅本地模式显示，静态部署自动隐藏）：**地图分层编辑**（地面图块 / 装饰多深度层 / 可走阻挡 / 脚本触发与地图直传 / NPC 出生点与入口，画布自适应铺满窗口，点选 NPC 或出入口即在右侧编辑其行走图、移动速度、属性、对话脚本与掉落）、脚本（GSP 文本）、NPC、物品、技能、升级与战斗数值、结局称号，以及**图片素材上传替换**（存为版本的一部分），另外还有**「装饰物」独立栏**（跨地图按**贴图源矩形**列出**共用模板**并显示出现次数/地图：坐标、深度层、深度微调、深度模式（自动下凸包 / **手画地基线** / 整体单一深度），预览上可拖控制点、空白单击加点、右键删点，黄线可越出贴图，青线自动跟随，可一键恢复自动地基线）；列表页（NPC/物品/技能等）**点击行即可切换选中项**，参数里含图片的字段（行走图/头像/图标/特效帧）**直接显示图片预览**

## 运行

```bash
# 1) 生成资源（本项目需与解包后的原版目录放在同一层；
#    在网页项目目录内执行，第一个参数是你的原版游戏根目录：
#    即含有 extracted/ map/ music/ 的那一层，此处为上一级 ..）
python build_assets.py .. assets
# 或： npm run build:assets

# 2) 启动本地服务器（必须走 HTTP；ES Module 不能用 file:// 直接打开）
#    用自带服务器（带 no-cache，改代码后不会被浏览器缓存旧模块）
python serve.py 8005
# 或： npm start
# 浏览器打开 http://localhost:8005/
#（若以前用过 python -m http.server，请先 Ctrl+Shift+R 硬刷新一次清除旧缓存）
```

> 需要较新的浏览器（原生支持 ES Module）。`package.json` 声明了 `"type": "module"`。

分层依赖方向（目标）：`engine ← content ← game/runtime ← editor`（箭头指向“被依赖”）；
`engine/` 为通用纯层，**不得依赖 `content/` 或 `core/`**，由 `tools/check-arch.mjs` 强制；
所有与具体游戏有关的数值/字段（移速、索敌、近战分界、等距几何、背包道具…）均由装配层
从 `config.json` 注入。当前处于渐进式改造，运行时仍经适配层消费新模型，
装配点收敛到 `runtime/context.js`。详见 `docs/ARCHITECTURE.md` 与 `docs/DATA_MODEL.md`。

## 数据版本与编辑器

游戏启动时会读取一个**数据版本**。所有版本都放在 `versions/` 目录下，**每个版本一个文件夹**：

```
versions/
  default/            最初默认版本（原版），只读
    version.json      版本元数据 { id, name, builtin, readonly, ... }
    assets/           原版全部数据（*.json + 图片/音频/地图）
  <id>/               编辑器 / 用户创建的版本（可写）
    version.json      元数据 + 名称
    patch.json        相对原版的“补丁”（只存不同之处）
    assets/           可选：本版本覆盖的数据/图片（先在 default 找，再在此覆盖）
```

- **默认版本**（`versions/default/`）= 原版数据，**只读、永不被修改**；编辑器打不开它去编辑。
- 在版本管理里选「复制」任意版本即可得到一个**可写副本**，再在其基础上编辑。
- **本地模式**（`python serve.py`，即 `localhost`/`127.0.0.1`）：`serve.py` 提供 `/__api__/versions`
  写文件后端，编辑器保存时**直接写入 `versions/<id>/` 文件夹**（便于版本管理、可纳入 git）。
- **静态部署**（任意域名，无写文件后端）：编辑器自动退化为**纯浏览器**存储
  （补丁存 `localStorage`、图片存 `IndexedDB`），并可导出为 `.gsxy.json` / `.gsxy.zip` 迁移。
- 启动顺序：`versions/default/assets` 原版数据 → 所选版本的 `patch` 覆盖 → 版本的图片覆盖。
- 图片按**逻辑键**（`assets/...`）引用：未覆盖的总是从 `versions/default/assets/` 加载，
  版本只需存放被覆盖的素材，无需复制整份资源。

「编辑内容」入口**只在本地模式显示**（`file://` 或 `localhost` / `127.0.0.1` / `.local`），
静态部署（任意域名）下自动隐藏；本机也可用 `?editor=1` 显式打开。
编辑器按需加载（`src/editor/`），不进入编辑器不会下载相关代码。

编辑器标签页：

| 标签 | 可编辑内容 |
|---|---|
| 地图 | **自适应铺满窗口的 iso 画布 + 分层编辑（每层默认「选择」且只能点选本层内容）**：① **地面**——选中格子后右侧显示行列与贴图缩略图并可直接换贴图；② **装饰**——悬停自动高亮、点选后右侧显示坐标/图片/类别/删除，按住左键可拖动，支持多个**深度层**，并可编辑**深度微调**（像素级前后微移）与**深度模式**（自动下凸包 / 手画地基线 / 整体单一深度；手画时预览可拖控制点、空白加点、右键删点），右侧还列出**本图装饰物列表**（缩略图点选即选中）；③ **碰撞**——二值，左键加碰撞、右键去碰撞；④ **标记**——点选地块后右侧编辑脚本触发/地图直传/入口勾选，Ctrl+C/V 复制粘贴地块选项；⑤ **单位**——单位/入口点缩略图列表，选中可拖动改位置，右侧为绑定的 NPC 属性（行走图动作×方向预览、头像、移动/追击速度、掉落、技能、可读的 AI 行为），并可勾选**「本实例独立配置」**单独覆盖模板。 |
| 脚本 | 全部 `.gsp` 剧情/交互脚本文本 |
| NPC / 物品 / 技能 | 数据表逐项编辑（属性、移动/追击速度、掉落物品、价格、图标、台词、特效帧…） |

| 标题结局 | 标题/结局音乐、结局背景图、片头闪屏、结局评价称号 |
| 图片素材 | 上传替换头像/物品图标/技能图标/界面图（存为版本的一部分，游戏中即时生效） |

## 逆向导出的关键结论（本轮新增）

- **对象表1**（276B/条）= **整体精灵**（`+0xFC/0x100` 源点、`+0x10C/0x110` 尺寸、`+0x104/0x108` 目标）+ 叠加 64×32 图块；
  只画图块会只剩地基/树干（见 `../docs/05-map.md` §3.1）。
- **对象表2**（32B/条）= NPC 出生点：`+0x00` NPC 编号、`+0x18` 行、`+0x1C` 列。
- **碰撞** = 格子 `+0x18`（`0` 阻挡 / `1` 可走）。
- **格子 `+0x1C`** = `scripts.ini` 脚本触发器；**`+0x1D`** = `maps.ini` 地图直传；表头 `+0x44/0x48` = 该地图入口点。
- **pmg 帧命名不统一**（`npc001_st2_080.bmp` / `路人_43.bmp` / `小孩_42.bmp` / `map032_1王老五_wlk_43.bmp`，
  填充可能是 `0xCC` 或 `0xCD`），必须按“动作名区间 + `*end*`”解析。
- **战斗**：随机数 `0x429300`（MINSTD）；命中 `roll <= role+0xa8c`；伤害 `role+0xa88 + 技能威力 − 防御/2`。
